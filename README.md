# Устойчивость цифровых водяных знаков

Исследование того, как частота повреждений объекта и фона при обучении влияет на чтение водяного знака после локального шума, стирания и генеративного редактирования в задачах DRM.

- [17 — Обучение](src/17-spatial-attack-training/experiment.ipynb): сравнение режимов обучения с разными типами и пространственным распределением повреждений.
- [18 — Перенос устойчивости](src/18-spatial-attack-transfer/experiment.ipynb): проверка обученных моделей на простых воздействиях, Big-LaMa и Stable Diffusion Inpainting.

**Данные:** COCO 2017 с сегментационной разметкой. Пилот: 5000 изображений для обучения, 500 для валидации и 500 для теста; 128×128, метка 16 бит, один seed. Основные маски объекта и фона занимают около 15% кадра.
